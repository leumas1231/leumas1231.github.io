MedBot is a user-focused automation system designed to streamline activity reporting and tracking for a multi-user community. The project replaced a manual submission and tracking process with a structured interaction flow that improves clarity, reduces administrative overhead, and provides users with consistent feedback. The primary goal was to simplify reporting while increasing visibility into progress and performance.


## Responsibilities

- Designed and implemented a structured reporting workflow to replace a manual tracking process.

- Developed a clear command and feedback system to reduce user confusion and input errors.

- Integrated automated data collection with a centralized tracking system.

- Maintained and iteratively refined the system based on real user feedback.

## Problem

The community relied on manual activity reporting and spreadsheet tracking, which resulted in:

- Time-consuming administrative work

- Inconsistent data entry

- Limited transparency into individual progress

- Increased potential for reporting errors

Users needed a simpler and more reliable way to submit activity reports and monitor their progress without increasing system complexity.


## Process & Impact
I approached MedBot as both a workflow optimization and interaction design challenge.

I began by evaluating the existing manual reporting process to identify inefficiencies and friction points. From there, I designed a structured command flow that minimized cognitive load and guided users through submissions with clear prompts and confirmation feedback.

- Mapped the manual reporting workflow to identify bottlenecks

- Designed simplified input structures to reduce ambiguity

- Implemented consistent confirmation and error messaging

- Automated data validation and centralized tracking

- Iteratively refined command flows based on user feedback

- Deployed and maintained the system within a hosted environment

## Results

- Replaced a fully manual reporting system with automated tracking

- Successfully processed 546+ activity submissions

- Supported 70+ active users

- Reduced administrative workload and reporting inconsistencies

- Improved transparency and clarity of user progress

## Reflection

MedBot reinforced the importance of designing for clarity in text-based interfaces where visual cues are limited. I learned that thoughtful interaction design, structured feedback, and iterative refinement can significantly improve user confidence and reduce friction. This project strengthened my ability to balance technical implementation with user-centered workflow design.
