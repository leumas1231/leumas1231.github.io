As an independent IT consultant, I worked with a local organization to evaluate and improve usability within a legacy Microsoft Access application. My focus was on streamlining workflows, reducing manual effort, and enhancing clarity within an existing system without disrupting operational continuity. A primary objective was enabling the owner to easily generate meaningful reports to better understand and manage business processes.


## Responsibilities

- Evaluated and improved user workflows within a legacy Microsoft Access application.
- Identified usability challenges and implemented interface and logic improvements using VBA.
- Collaborated with business stakeholders to understand user needs and translate them into system enhancements.
- Performed testing and validation to ensure changes were reliable and did not disrupt existing workflows.


## Problem

The organization relied on a legacy Microsoft Access application to manage internal workflows. Over time, the system became difficult to navigate and maintain due to:

- Inconsistent form behavior

- Manual processes that increased user effort

- Limited feedback for user actions

- Growing complexity in logic and reporting

Users needed a more streamlined, intuitive workflow without requiring a complete system overhaul.

## Process & Impact

I began by analyzing the database structure, form layouts, and existing VBA logic to understand how users interacted with the system and where friction occurred. I also collaborated closely with the stakeholder to document requested changes and prioritize enhancements based on workflow impact.

- Mapped user workflows to identify bottlenecks and redundant manual steps

- Identified usability challenges in form design and interaction feedback

- Implemented VBA enhancements to automate repetitive tasks

- Simplified form logic to create clearer, more predictable interactions

- Collaborated directly with stakeholders to translate operational needs into practical improvements

- Tested and validated changes to ensure reliability and minimize disruption


## Reflection

Working within a legacy system reinforced the importance of balancing user needs with technical constraints. I learned that meaningful UX improvements often come from careful workflow evaluation and incremental enhancements rather than rebuilding from scratch. This experience strengthened my ability to analyze user behavior, simplify complex processes, and deliver practical solutions within real-world limitations.
